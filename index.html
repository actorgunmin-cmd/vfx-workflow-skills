호출 예: $colmap-vfx 내 영상의 카메라를 추적하고 지면 격자 오버레이로 검수해줘.

  1. 01. 샷 전체 파이프라인 — 개별 ZIP (SKILL.md·코드 포함)

    실사 플레이트에 여러 VFX 단계를 연결해 완성 샷과 편집 가능한 중간 산출물을 만든다. 트래킹·로토·생성·렌더·합성을 함께 요청한 작업에 사용한다.

  2. 02. COLMAP 카메라 트래킹 — 개별 ZIP (SKILL.md·코드 포함)

    이동 카메라의 실사 영상에서 COLMAP 카메라와 희소 점군을 복원하고 CG용 정렬 데이터를 만든다. 카메라 위치가 필요한 매치무브 요청에 사용한다.

  3. 03. PnP 포즈 복원 — 개별 ZIP (SKILL.md·코드 포함)

    알려진 3D 점과 영상의 2D 대응점으로 OpenCV PnP 포즈를 계산해 CG 카메라나 물체를 맞춘다. 이미 3D 기준점이 있는 트래킹에 사용한다.

  4. 04. 포인트·평면 트래킹 — 개별 ZIP (SKILL.md·코드 포함)

    CoTracker 또는 OpenCV와 사용 가능한 트래커로 점·평면을 추적해 패치, 레터링, 작은 CG 요소를 붙인다. 2D 부착과 국소 합성에 사용한다.

  5. 05. 코드 기반 3D·셰이더 — 개별 ZIP (SKILL.md·코드 포함)

    OpenGL/WebGL/GLSL 또는 사용 가능한 코드 렌더러로 단순 조형과 시뮬레이션을 만들고 실사 카메라에 맞춰 렌더한다. DCC 없는 CG 실험에 사용한다.

  6. 06. 천막·천 시뮬레이션 — 개별 ZIP (SKILL.md·코드 포함)

    추적된 실사 공간에 고정점을 가진 천/천막을 시뮬레이션하고 합성용 패스를 만든다. 바람·처짐이 있는 천 CG에 사용한다.

  7. 07. FOOH·CG 삽입 — 개별 ZIP (SKILL.md·코드 포함)

    추적된 실제 공간에 CG 물체를 넣어 원근·가림·조명·그림자를 맞춘다. Blender 또는 사용자가 선택한 렌더러 기반 FOOH에 사용한다.

  8. 08. 키잉·로토·디스필 — 개별 ZIP (SKILL.md·코드 포함)

    크로마키 alpha와 green spill을 정리해 합성 가능한 전경을 만든다. 비크로마 영상의 정밀 인물 로토는 정밀 실루엣·비디오 매팅으로 처리한다.

  9. 09. 클린 플레이트·리무브 — 개별 ZIP (SKILL.md·코드 포함)

    영상의 사람·표지판·물체를 지우고 시간적으로 일관된 배경을 복원한다. 배경 생성 전의 인물 제거에도 사용한다.

  10. 10. 뎁스·노멀·리라이팅 — 개별 ZIP (SKILL.md·코드 포함)

    영상의 depth/normal과 전경 매트를 이용해 조명 방향·색·효과광을 바꾼다. Glow Jam류의 2D 리라이팅과 폭발광 합성에 사용한다.

  11. 11. 배경·계절 교체 — 개별 ZIP (SKILL.md·코드 포함)

    실사 인물을 보존하면서 이동 카메라의 배경을 바꾸고 리라이팅해 합성한다. 설경/하늘/공간 교체에 사용한다.

  12. 12. 국소 생성·소품·눈 디테일 — 개별 ZIP (SKILL.md·코드 포함)

    전체 영상을 보존하면서 일부 구역의 물체·군중·소품·작은 그래픽만 교체하거나 추가한다.

  13. 13. 플레이트·긴 아트워크 확장 — 개별 ZIP (SKILL.md·코드 포함)

    실사 플레이트나 그래픽을 이어 배치하고 화면 밖을 확장해 긴 아트워크와 카메라 이동용 배경을 만든다.

  14. 14. 레터링·캐릭터 모션 — 개별 ZIP (SKILL.md·코드 포함)

    실사 공간이나 화면에 레터링과 작은 2D 캐릭터 모션을 추가한다. 손그림 글씨·달리는 캐릭터·공간 부착 그래픽에 사용한다.

  15. 15. 무빙 포토 — 개별 ZIP (SKILL.md·코드 포함)

    정지 사진의 일부 요소를 움직이고 주요 인물·구도는 유지하는 무빙 포토를 만든다.

  16. 16. 벡터 조형 리텍스처 — 개별 ZIP (SKILL.md·코드 포함)

    여러 벡터 실루엣을 같은 재질·조명 체계로 리텍스처한다. 눈 결정·서리처럼 형태 일관성이 필요한 그래픽 세트에 사용한다.

  17. 17. Start/End 몰핑 — 개별 ZIP (SKILL.md·코드 포함)

    시작·끝 이미지로 방향성이 있는 몰핑/전환을 만들고 리타임·보간으로 연결한다.

  18. 18. 오디오 리액티브 — 개별 ZIP (SKILL.md·코드 포함)

    음악의 비트/에너지 곡선을 이미지 조건 전환과 그래픽 애니메이션에 연결한다. ComfyUI·AnimateDiff·IPAdapter 기반 음악 반응 영상에 사용한다.

  19. 19. 충돌·폭발 VFX — 개별 ZIP (SKILL.md·코드 포함)

    충돌의 시작·끝 상태를 설계하고 생성 소스와 원본 인물·효과광·연기를 합성한다.

  20. 20. 마커 기반 VFX 지시 — 개별 ZIP (SKILL.md·코드 포함)

    영상 속 색 점·면·프록시로 생성/변형 위치를 지시하고 원본에 통합한다.

  21. 21. 매트→구름·빛·잔상 — 개별 ZIP (SKILL.md·코드 포함)

    로토 매트 자체를 디자인 소스로 사용해 구름·빛·잔상·그래픽 텍스처 애니메이션을 만든다.

  22. 22. 캐릭터·배경 연속성 — 개별 ZIP (SKILL.md·코드 포함)

    여러 샷에서 캐릭터·의상·배경·룩을 일관되게 유지하도록 시트와 샷별 기준 이미지를 만든다.

  23. 23. 퍼포먼스 전이 — 개별 ZIP (SKILL.md·코드 포함)

    연기 레퍼런스의 표정·동작을 목표 캐릭터에 전달한다. Act-two류 연기 구동 워크플로우에 사용한다.

  24. 24. After Effects 자동화 — 개별 ZIP (SKILL.md·코드 포함)

    연결된 MCP 또는 지원 스크립트로 After Effects 합성·레이어·효과·키프레임 작업을 실행하고 결과를 검증한다.

  25. 25. ComfyUI 워크플로우 구성 — 개별 ZIP (SKILL.md·코드 포함)

    실제 설치 노드·모델을 확인하고 이미지 조건·AnimateDiff·IPAdapter·보간 등 VFX용 ComfyUI 그래프를 구성하거나 수리한다.

  26. 26. 시간 일관성·보간·업스케일·마감 — 개별 ZIP (SKILL.md·코드 포함)

    생성/합성 영상의 리타임·보간·업스케일과 최종 인코딩을 수행하고 시간축 품질을 검수한다. 원본과의 정밀 정렬·색 매칭만 요청하면 해당 전문 스킬로 처리한다.

  27. 27. AI·원본 프레임 정렬 — 개별 ZIP (SKILL.md·코드 포함)

    AI 영상과 원본의 시간·구도·카메라 움직임을 정렬한다. 원본 인물 재합성 전의 프레임 대응·크롭·워프에 사용한다. 색감만 바꾸는 요청은 별도 색 매칭으로 처리한다.

  28. 28. 원본 기준 색감·질감 매칭 — 개별 ZIP (SKILL.md·코드 포함)

    AI 영상의 노출·화이트밸런스·대비·블랙·채도·그레인을 원본 플레이트에 맞춘다. 원본과 생성 영역의 이질감을 줄이는 합성과 샷 매칭에 사용한다.

  29. 29. 정밀 실루엣·비디오 매팅 — 개별 ZIP (SKILL.md·코드 포함)

    MatAnyone/MatAnyone 2 등 사용 가능한 비디오 매팅으로 원본 인물의 정밀 alpha를 만든다. 머리카락·모션블러·손가락 틈·시간 안정성이 필요한 원본 전경 복원에 사용한다.

  30. 30. AI 배경 위 원본 인물 재합성 — 개별 ZIP (SKILL.md·코드 포함)

    AI 영상 위에 원본 인물·소품을 다시 합성해 얼굴·연기·손 디테일을 보존한다. 정밀 로토·시간/기하 정렬·가림·경계 색을 연결하는 작업에 사용한다.
